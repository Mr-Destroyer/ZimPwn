## 🖥️ About  

`ZimPwn` is a proof-of-concept / penetration-testing script written in Python.  
It’s built for educational red-team labs and legal testing environments.  

Main files:  

- `pwn.py` — main script  
- `install.sh` — quick installer for requirements

## How to install

```bash
# Clone the repo
git clone https://github.com/Mr-Destroyer/ZimPwn.git
cd ZimPwn

# Install requirements
chmod +x install.sh
./install.sh

# Run the script
python3 pwn.py
```
